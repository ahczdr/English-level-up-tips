# 手机与平板个人英语学习工具开发计划

> 状态：方案草案，供确定开发范围使用。此次仅创建计划，尚未开发产品或验证学习效果。
> 后续实施按阶段拆成可验证的小任务，可使用 superpowers:executing-plans 或 superpowers:subagent-driven-development 跟踪执行。
> 内容方向已明确为高考英语，后续执行以[高考英语详细开发计划](gaokao-english/README.md)为准；本文件保留为早期范围记录。

**Goal:** 为英语基础薄弱的高中生提供每天 10-15 分钟、触屏友好、能够积累学习成果的个人英语练习工具。

**Architecture:** 新增独立学习应用，原 VitePress 站点保留为方法资料库。首版本地保存学习记录，通过带版本的课程包驱动练习和复习；离线支持以明确下载成功的资源为边界。跨设备自动同步和 AI 服务在后续阶段独立接入。

**Tech Stack:** 拟采用 Vue 3、TypeScript、Vite、Vue Router、IndexedDB、PWA、Vitest 和 Playwright。具体依赖版本在开发开始时根据 Node.js 24 环境及兼容性固定。

## 1. 范围与假设

- 首要用户：英语基础薄弱的高中生，个人使用，不设班级或教师管理后台。
- 优先目标：愿意开始、能完成短练习、隔天仍能回忆，而不是承诺考试提分。
- 设备默认覆盖 iPhone、iPad、安卓手机和安卓平板。兼容目标暂定 iOS/iPadOS 17 及以上、安卓当前稳定版 Chrome，具体系统版本以实际设备清单收敛。
- 每天默认 10-15 分钟；可选择 5 分钟轻量任务，不强制限时。
- 课程从基础词块、简单句和简短听力开始；学校教材版本尚未指定，首版采用原创通用内容，不标为某教材同步课。
- 首版设备之间独立保存记录，提供手动备份迁移。自动同步另列阶段，不把适配多种设备等同于共享学习进度。
- 前期不收费、不投放广告、不上应用商店，不接入公开排行榜、陌生人社交或家长监控。

## 2. 路线选择

| 路线 | 优点 | 代价 | 决策 |
| --- | --- | --- | --- |
| PWA 网页应用 | 一套触屏界面覆盖手机与平板，可通过链接试用、添加主屏幕 | 安装入口、音频、离线存储需分设备验证 | 首版采用 |
| Flutter 等跨平台客户端 | 更直接地使用原生能力，适合长期移动产品 | 增加客户端构建、签名、分发工作 | 使用稳定后再评估 |
| 微信小程序 | 适合已有微信使用习惯 | 依赖平台账号、审核与能力约束 | 暂不作为首版路线 |

PWA 通过 HTTPS 提供。手机访问电脑的局域网 HTTP 地址只能用于部分页面预览，不能据此验收安装和离线能力。开发阶段需要可信 HTTPS 测试入口；对外部署另按实际目标准备。

## 3. 参考项目与复用边界

| 项目 | 借鉴什么 | 触屏产品怎样调整 |
| --- | --- | --- |
| Qwerty Learner | 即时纠错、发音、词库分层、默写 | 将大量键盘拼写改为配对、点选字母和少量输入，保留隐藏答案后回忆 |
| TypeWords | 词句结合、错词记录、文章练习、本地数据 | 拆成单屏短题，课文只展示短段落，键盘弹出后仍能看到题目 |
| Earthworm | 从词到短语再到句子的渐进练习 | 点词组句后再撤掉词块提示，以新句检查迁移 |
| AnkiDroid | 到期复习、间隔重复、学习记录 | 首页只给出少量到期任务，不让学生配置复杂参数 |
| MuJing | 短片段重复播放、字幕辅助 | 首版采用原创短音频、手动重播与文本提示，不引入影视播放器 |
| 当前指南仓库 | 学习状态、首版与修改版、每周复盘 | 将复杂表格缩成少量动作与一页可读的周报 |

默认借鉴交互与方法，独立实现首版。直接复制代码、课程或音频前逐项记录来源和许可；这些项目的许可不同，不能把它们当作可以无条件拼接的代码包。课文、图片、音频各自登记来源，不从公开链接推断可再分发权限。

## 4. 一次学习的完整流程

1. 首次进入选择目标：跟上课本、补基础、改善听力；选择 5/10/15 分钟。
2. 用 8-10 道短题了解词义、简单句和听辨起点，可跳过。不输出正式 CEFR 等级，也不据此判断考试能力。
3. 首页显示一个明确任务，如“今天学会介绍自己的学校”，并显示预计时长。
4. 先复习到期项目，再学习 3-5 个新词块和 1 个基础句型。
5. 练习顺序：听读并理解、辨认或配对、点词组句、隐藏提示回忆。
6. 错题给出中文解释和一个对比例句；重新作答后继续，不扣生命或强制重做整关。
7. 结束页展示本次独立完成的内容、需要再练的一项及下次复习安排。
8. 第 7 天使用未见过的同难度短句复测，区分熟题记忆与新题应用。

## 5. 首版页面与交互

| 页面 | 内容 | 验收重点 |
| --- | --- | --- |
| 今日 | 今日任务、到期复习、继续上次练习、轻量模式 | 打开后能直接进入练习，中断后能继续 |
| 练习 | 图片/文字、音频按钮、选项或词块、反馈 | 操作无需悬停、无强制拖拽、无默认倒计时 |
| 复习 | 错误词块、到期词句、主动回忆 | 显示提示后的完成不记为独立掌握 |
| 成长 | 已完成单元、作品、前后对比、周报 | 明确区分首次正确、提示后正确和延迟复测 |
| 我的 | 时长、音效、文字大小、课程下载、备份恢复 | 音效可关闭，备份可校验，清除数据需明确确认 |

手机采用单列和底部主操作，平板根据可用宽度采用材料与练习双栏；分屏不足时回到单列。按钮目标至少 44 CSS 像素，文字可放大，不能仅靠颜色表示对错。支持横竖屏、屏幕安全区、软键盘遮挡处理和减少动画偏好。

输入训练不是完全取消：先通过点击词块降低操作负担，之后用少量文字输入或纸笔自测检查拼写。软键盘自动纠错对评分的影响需要标注；无法可靠关闭时不把输入成绩作为严格拼写测验。

## 6. 兴趣设计

- 采用简洁的探索地图，每个单元对应一个真实小目标，如自我介绍、校园生活、兴趣、计划。
- 默认任务 5-8 题一组，可中途保存；有余力再主动选择加练。
- 奖励完成练习和订正错误，每个学习任务只记一次进展，重复点击和刷熟题不重复刷奖励。
- 完成单元获得一张“我会表达”的句子卡，可回看本人的初稿和改进结果。
- 每周展示实际学会的内容，不使用羞辱性等级，不因漏学一天清空累计成果。
- 音效和短动画仅作为反馈，均可关闭；不设置随机付费奖励或公开排名。
- 是否提高兴趣由真实使用反馈决定：记录开始阻力、完成情况、主动返回及主观难度，不把游戏奖励次数等同于学习效果。

## 7. 首批课程与评分

首版目标是 14 天内容，6 个生活与校园主题，约 60-80 个基础词块、10-12 个句型。第 7 天和第 14 天以复习及未见题复测为主，具体数量由内容审核与试用调整。

每个词块或题目包含稳定 ID、课程版本、目标技能、题干、候选答案、可接受答案、中文解释、音频路径、来源记录、难度与关联复习项目。组句支持列明的合理答案，不仅按唯一字面顺序评分；大小写、空白和允许省略的标点需有明确归一化规则。

题型包括词义辨认、词义配对、听音选词、点词组句、短句填空、少量输入。选择题答对只能计入辨认表现，不能单独升级为掌握。分开记录首次作答、重试次数、提示使用和后续独立回忆。

首版采用可解释的固定复习间隔：在原题次日、第 3 天、第 7 天及第 14 天安排复习，错误回到较短间隔。它是可调整的初始规则，不宣称为个体最优记忆算法；后续有足够使用记录再评估 FSRS。

每天先处理到期内容再安排新内容；超过用户时长预算时保留积压并减少新题，不能静默丢弃复习记录。复习日期按个人设置的本地学习日计算，保留时间戳，处理午夜、时区变化与同一题重复提交。

首批音频在构建课程包时准备并审核，不依赖每次学习实时调用 TTS。无音频或播放失败时可跳过听力题并完成文字训练，但该题不记为听力达标。机器生成的题目与语音均需人工复核。

## 8. 技术结构与数据

计划新增以下目录，开发时固定各入口与脚本，保持原站点命令可继续使用：

```text
apps/english-practice/
  package.json
  src/
    app/                 路由、导航、启动与错误恢复
    features/onboarding/ 目标设置与起点练习
    features/today/      今日任务与恢复入口
    features/practice/   题型渲染、答案判定、音频
    features/review/     到期队列与复习规则
    features/progress/   学习成果与周报
    features/settings/   下载、备份、显示与声音设置
    data/                IndexedDB、迁移与导入校验
    content/             课程结构校验和课程索引
  public/packs/          原创课程 JSON 与音频
  tests/                 规则测试与浏览器流程测试
planning/                计划、验收记录与后续设计
```

个人设置、作答记录、复习状态、会话进度、课程下载状态分别保存。作答记录使用唯一 ID，提交、安排复习和进展更新保持一致，避免页面刷新或连点造成重复记账。

IndexedDB 保存学习记录，Cache Storage 保存版本化课程资源。课程包完整下载并校验后才标为“可离线”；更新先保留旧包，确认新包可用再替换。服务工作线程更新不在练习中强制刷新。

备份采用带 schemaVersion 和课程版本的 JSON，首版不含用户录音。导入先检查格式、版本和大小，展示记录数量，失败不修改原数据；首版采用明确的整库恢复，不提供未验证的跨设备自动合并。

浏览器存储可能被清理，不能当作永久备份。引导用户从固定的主屏幕入口使用，并提供导出提示；Safari 标签页与主屏幕应用可能使用不同存储，安装前后要验证或提供迁移引导。

## 9. 分阶段开发与验收

预估以下为一名熟悉技术栈的开发者集中投入的工作日，不是承诺工期。素材准备、真实设备条件及试用反馈会影响排期。

### 阶段 A：触屏样板与内容样例，2-3 个工作日

- [ ] 准备 1 个原创单元、约 8 道样题及审核过的短音频。
- [ ] 实现今日、练习、结果三个可操作页面。
- [ ] 验证点选、组句、错误解释和继续流程。
- [ ] 在手机和平板检查字重、字号、横竖屏和软键盘。
- [ ] 让真实使用者独立完成一次短练习，记录需要指导的位置。

交付：触屏交互样板。验收要求是不看开发说明能开始并完成练习；此阶段不把临时页面当作数据完整的正式版本。

### 阶段 B：可持续使用的核心版本，5-7 个工作日

- [ ] 建立课程结构校验、答案归一化和多答案判定。
- [ ] 实现词义、听辨、组句和少量输入题型。
- [ ] 实现作答保存、会话恢复和到期复习。
- [ ] 实现提示与独立作答的分开统计。
- [ ] 增加固定时长任务和轻量任务。
- [ ] 逐条验证重复提交、刷新、午夜和超量复习的处理。

交付：可连续练习的个人工具。验收要求是重新打开后能恢复，错题会进入后续复习，重复提交不增加成果。

### 阶段 C：课程、兴趣反馈与移动交付，4-6 个工作日

- [ ] 完成 14 天原创内容、解释与音频的审核。
- [ ] 实现探索地图、句子成果卡和周报。
- [ ] 实现 PWA 安装说明、课程下载与离线状态。
- [ ] 实现备份导出、恢复预检及存储失败提示。
- [ ] 验证安装入口、断网、更新、音频失败和 Safari 独立存储。
- [ ] 完成 HTTPS 真机测试入口的准备和访问验证。

交付：可安装到主屏幕的 v0.1 候选版本。验收要求是下载课程后断网仍可完成文字与已缓存音频练习，备份可在另一设备恢复。

### 阶段 D：7 天试用与修正，7 个自然日，另留 2-3 个工作日修正

- [ ] 记录是否能独立开始、是否完成、哪里退出及任务实际耗时。
- [ ] 每次结束收集“太简单 / 合适 / 太难”的可跳过反馈。
- [ ] 第 7 天用未见过的同难度题比较独立回忆和组句。
- [ ] 根据实际困难调整题量、解释与点击步骤。
- [ ] 汇总缺陷、学习表现与未验证边界，再决定下一阶段。

交付：试用记录、缺陷修复和下一版范围。单人短期变化仅用于改进产品，不宣称因果或高考提分效果。

总计约 13-19 个开发工作日，加 7 天真实试用。首轮以 3-5 周日历时间安排较合理，取决于连续投入和素材准备。

## 10. 后续阶段

- v0.2：手机与平板自动同步。增加个人身份验证、服务端数据、增量同步、冲突规则及删除机制；单独验证两设备离线作答后合并不会重复奖励或丢失记录。
- v0.3：跟读录音和 AI 辅导。先做录音回放与前后比较，再接服务端 AI 解释；提供上传授权、失败降级、请求限额与录音删除。识别文本不等同于发音评分。
- v0.4：按实际教材版本整理同步内容、阅读理解和基础语法模块；根据连续使用记录评估间隔调度升级。

首版必须在没有 AI 密钥时完整可用。AI 输出只作为反馈，不能直接用作唯一评分标准。

## 11. 验证清单

| 层面 | 必须通过的检查 |
| --- | --- |
| 规则 | 多答案判定、提示统计、复习日期、重复提交、奖励只计一次 |
| 数据 | 刷新恢复、迁移失败保留原数据、损坏备份拒绝、存储写入失败可见 |
| 内容 | 每题有有效答案和解释，引用资源存在，音频与文本一致，难度经人工复核 |
| 浏览器 | 完成单元、订正、恢复、到期复习、导出导入、课程更新 |
| 真机 | 至少一台 iPhone、一台 iPad、一台安卓手机；安卓平板拿到设备后单列补验 |
| 离线 | 只对已完整下载的课程承诺离线，未下载资源有明确说明 |
| 可用性 | 横竖屏、平板分屏、软键盘、触控目标、文字放大、关闭声音与动画 |
| 原仓库 | 新应用独立构建；变更涉及根目录脚本时运行原站点检查与构建 |

Playwright 的设备模拟仅用于布局和流程回归，不能代替真实 Safari/Chrome 的安装、音频和存储验证。没有对应真机时明确记录待验，不标为全部通过。
