## 目标与允许变更

在独立应用目录建立可安装、可检查、可构建、可操作的 Vue 触屏入口。所有下列路径均相对于应用目录：

- 工程文件：`package.json`、`package-lock.json`、`index.html`、`tsconfig.json`、`tsconfig.node.json`、`vite.config.ts`、`eslint.config.js`。
- 应用文件：`src/main.ts`、`src/app/App.vue`、`src/app/router.ts`、`src/styles.css`、`src/features/today/TodayPage.vue`。
- 测试：`tests/unit/app.spec.ts`；必要的真实测试配置、类型声明和 T01 浏览器冒烟测试可在应用内新增，交付时逐项说明用途。

实现要求：

1. 独立 npm 工程，不将根目录改为 workspace，不改原书稿依赖；包名 `gaokao-english-practice`，版本 `0.1.0`，`private: true`，ESM，Node engines 为 `>=24 <25`。
2. 按 T01 列表安装运行和开发依赖，全部使用精确版本并生成独立 lockfile。回传 registry 实际版本、engines、peer dependencies 兼容检查摘要；不忽略冲突、不使用强制安装绕过错误。安装 PWA 依赖不代表本任务实现 PWA。
3. TypeScript 严格模式；ESLint 使用 Vue+TypeScript flat config；Vitest 使用 jsdom。不得靠关闭关键规则或允许无测试通过来满足门禁。
4. 使用 `createWebHashHistory()`，根入口导向 `/#/today`。首页有可访问名称为“开始今日练习”的按钮，点击显示明确无课程提示，不创建虚假会话、课程或成绩。空态可以在当前页面展示，无需提前建立下载页面。
5. 按 P05 提供最小响应式布局；触控目标至少 44x44 CSS px，正文默认 18px，可缩放至 200%，不依赖悬停或拖动。无需复杂动画。
6. 保留计划定义的 dev/preview 端口、strictPort 和 hash 路由约定；端口被占用时回报主代理，不杀其他进程、不暗换端口。
