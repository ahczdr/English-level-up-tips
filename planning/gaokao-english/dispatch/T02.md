## 冲突审查与冻结口径

### 1. 结构校验与发布门禁分层

原 T02 明确要求样例 preview 成功；P07 正式规模、备用平行题、听力覆盖、审核要求不能无条件套到 preview。所有模式仍执行结构、有效引用、答案、安全规则；只有 release 执行正式审核和发布规模限制。

- `validatePack(input: unknown, purpose: 'preview' | 'release')` 为纯函数，返回 `{ok:boolean, errors:Array<{path:string,code:string,messageZh:string}>}`。非法输入返回错误，不因输入类型错误直接崩溃。
- 保留原计划的两参数调用。它只校验包内结构/语义及单包 release 条件，不读取磁盘、联网、硬编码默认 profile 或检查整套 P07 数量。
- 单包 release 必须 status=published，author/reviewer 去首尾空白后均非空且不同，reviewedAt 为真实有效的 ISO 日期/时间；这些字段校验不等于核实真人审核。
- profile 引用由组装后的集合检查解析，真实资产 bytes/hash 由 Node I/O 层检查，全集数量由 release 层检查。不得因为纯函数返回成功就宣称这些外部约束已满足。
- 所有错误使用稳定代码、具体字段路径及中文说明；对能够安全继续检查的错误聚合报告。IO 错误带文件路径，不输出凭证、正文或整个输入对象。

### 2. ID、family 和 profile 的真实作用域

- D02 没有 family 实体表，不创建虚构 `families` 字段。family 从本包 Item.familyId 集合派生；Unit.familyIds 必须与其引用 Item 的 family 集合相等，比较集合而非排序。
- Source/Asset/Resource/Item/Unit 各集合内唯一，禁止错误实施“整个包所有 ID 全局唯一”。同名 resource 与 family 合法；两个不同资源的 `p1` 合法。
- paragraph ID 在所属 Resource 内唯一；gap ID、token ID、choice/shared option ID 在所属题目/集合内唯一。不同题目重复 `a`、`g1` 合法。
- gap 本地选项只在各 gap 内要求唯一。整题 distractors 只有 optionId，没有 gapId：引用必须在该题所有可用选项中恰好定位一项；若跨 gap 重名导致该引用不唯一，返回 `AMBIGUOUS_OPTION_REF`，不猜、不新增字段。没有歧义引用的本地重复 ID 本身不据此拒绝。
- profile 位于包外。CLI 对 `profileIds` 在已加载 profiles 中解析，并检查 Item.section 在所引用 profile 的允许范围内；默认 profile 必须保留 null 地区/年份、verified=false、allowMockExam=false、scoring=null。只启用专项但没有对应 Item 不构成 preview 错误。
- skillIds/prerequisiteSkillIds 没有独立词典，当前仅检验 ID 格式及集合重复，不编造技能外键表。

### 3. 答案、题型与预览规模

- D03 的“答案在选项中”只用于 choice/options gaps。text gaps 的 accepted 是非空文本，不能按 ID 正则校验；order 的答案是 token ID 全排列，writing 不进入客观答案校验。
- 所有对象层级拒绝未知字段，必填字符串按用途检查非空；source.url 可为 null，Resource 无音频可为 null，合法空数组按 D02/题型保留，不能一概要求非空。
- choice 2-7 选项且 answerOptionId 存在；order 至少一个 acceptedOrders，每个恰好包含所有 token ID 一次；同词不同 token ID 合法。
- gap 必须在 segments 中恰好出现一次；accepted 非空；options 使用共享或逐空本地选项，两者互斥。text 模式两类 options 都为空，每个 Gap.explanationZh 非空。
- uniqueOptions 校验是否存在覆盖全部 gap 的互异答案分配，不以“每个空的第一个答案不重复”代替可行性检验。
- gap-reading 必须 options/共享选项/uniqueOptions=true，release 要求 5 空/7 选项；preview 可容纳明确教学规模。cloze 使用本地选项且 uniqueOptions=false；grammar 使用 text。样例 G0 两空 cloze 和一空 grammar 必须通过 preview。
- 阅读/听力为 choice，绑定有效 Resource，至少一条 evidence；其 resourceId 必须匹配题目材料，paragraphId 可解析，非空 quote 是原段落的精确子串。
- writing 的 wordRange 为正整数且下限不大于上限；应用文 openingSentences 为空，续写允许 0 或 2 条，2 条时均非空。不从地区空配置推断官方字数/分值。

### 4. 听力与素材字节

- 无 listening Item 的文字包允许 assets=[]，不凭 profile.enabledSections 造音频。
- 实际 listening Item 在 preview/release 都必须有可解析的本地 audio Asset；release 另要求非空 transcript。必须验证缺引用、缺文件、MIME 类型不符等负例，不能因当前样例无音频绕过。
- Asset.path 是包内 `assets/...` 路径；例如 `assets/a.mp3` 映射到作者目录 `content/assets/a.mp3`，不是 `content/assets/assets/a.mp3`。
- 拒绝绝对路径、外部 URL、反斜杠、`.`/`..` 路径段及编码后的路径绕过；解析后的文件必须仍在指定素材根内，拒绝符号链接逃逸。校验输入输出路径，不能只检验字符串前缀。
- 作者 Asset.bytes/sha256 是声明值；对实际字节计算并比较，不静默修正错误 hash 使输入通过。实际摘要是 64 位小写 hex，bytes 为实际非负整数文件长度；零长度音频无效。
- 真实播放/听审不在 T02。测试可临时生成明确标记的二进制用于摘要路径测试，但不得把任意字节冒充可播放音频，更不得纳入正式计数。
- 纯文本内容拒绝 HTML 标签和脚本载荷，不执行输入；来源 URL 只接受合法 HTTP(S) 引用且不自动下载，不把 Source.url 当作媒体路径。

### 5. P07 无法从 D02 完整证明，必须失败关闭

真实缺口：D02 没有“词义/词块目标类别”“对话/独白及听审证明”“24 次新课+6 次复盘安排”字段。familyId 是评分类家族，不足以证明一个教学目标或三个不同题干；reviewer 字符串也不能证明真实人员审核。

本批冻结以下保守行为，禁止按 ID、题干关键词、文件名猜这些事实：

- 对所有包先做基础校验。release 的 eligible 集合只包含 published 且通过单包 release 校验的包；draft/reviewed 不计数。只有 draft 时明确输出未发布和数量不足，不能返回成功。
- 实现 D02 可支持的分项诊断：客观原子项、写作种类、句子题、阅读 Resource 分组及 G0/G1/G2 题量、5空/7选项七选五、10/15空完形、10空语法、听力材料/题量、family 同 reviewMode 备用题数量。
- 对照 P07 分项检查：24 句子项；阅读各层至少6篇且每篇至少3题；6 篇完整七选五；至少4篇10空和4篇15空完形；12篇10空语法；20段听力且至少30题；6应用文和4续写。718 仅为总量诊断，不能替代分项门槛。
- 词汇仅报告 candidate family、Item 和不同题干数量，不将这些直接认定为80词义+40词块目标。当前元数据不能证明的目标分类、听力类型/听审、30次安排分别返回 `RELEASE_EVIDENCE_UNAVAILABLE`，messageZh 标明缺哪种依据。
- 同 pack ID 多版本不能一起充量：当前作者目录每个包仅一个 manifest，release 拒绝同 ID 多版本候选；跨包重复 Item/Resource ID 不重复计数，同 ID 异内容报冲突。不同 ID 但相同材料/题干不作为独立新材料证据；为数量检查用稳定结构内容签名识别完全重复，不做模糊语义判断。
- 不实现恒定 `throw` 或永远退出1的假 release 命令。结构、审核、每个可计算阈值都必须有独立正反测试；当前没有证据表达方式的条件在报告中列为未可验证，整体 release 非零退出。
- 正式内容的真实作者/独立审核、语音听审、目标身份和学习安排须在后续内容生产契约补齐后解除阻断。当前 T02 有界技术验收可 PASS，但“完整发布门禁已完成”和“内容可发布”不得标为 PASS。

### 6. 稳定组装、catalog 与不可变版本

- D08a manifest 严格对应其列出的字段，引用数组不允许重复/缺失；单实体文件名 ID 与内容 ID 一致。Source/Asset 从各自 catalog 获取；各 manifest 独立组装完整 CoursePack，不隐式从其他包补外键。
- 实体数组按 manifest 顺序组装，保留题目/段落/选项顺序，不随机遍历文件系统。输出 JSON 递归稳定排序对象键，数组原序；不得加入构建时间等漂移字段。
- `content:build` 默认 preview，支持显式 `--mode preview|release`；未知模式非零退出。release 构建必须先通过全部 release 门禁，当前因此不能产出正式 catalog。
- 默认生成根是应用 `public/`，由 Vite 复制到 dist；CLI 测试允许注入临时作者根与输出根，绝不能向计划目录写入。
- 本批固定 catalog 形状为 `{schemaVersion:1, mode:'preview'|'release', packs:Array<{id,version,path,bytes,sha256}>}`；按 id/version 稳定排序。preview 标识必须保留；包 JSON 内 status 仍为 draft，不将预览产物伪称发布包。
- pack 路径固定 `/packs/<id>/<version>/pack.json`，媒体在同版本目录的 `assets/`。catalog bytes/hash 对应最终 pack.json 的实际 UTF-8 文件字节，不是对象内存大小或摘要字段占位。
- 所有校验/资产读取先完成，先写临时区并复核，再发布不可变目录，最后以同文件系统的原子重命名替换 catalog。任意阶段失败非零退出；旧 catalog 保持原字节，新 catalog 不能引用缺失或未校验产物。失败后可残留未引用的新版本，但不得显示构建成功。
- 已存在同 id/version 且内容/媒体相同则幂等复用；同版本不同字节拒绝覆盖。保留无关旧版本；不通过删除输出根重建绕过不可变检查。

### 7. repository 的最小边界

- 接收已校验包集合，提供 `getPack(id, version): CoursePack | undefined` 和 `getItem({packId,packVersion,itemId}): Item | undefined`。查询精确匹配，不自动回退最新版。
- 同 key 不同内容拒绝注册，避免静默覆盖；查询不能让调用者修改内部集合，可返回防御性副本。
- 不伪造 D04 学习服务错误或先实现 learning.ts。T03 再将缺包映射为 CONTENT_MISSING。

## 实施顺序与必测矩阵

每步先建真实失败用例，记录红灯原因，再实现并复跑；环境失败不算行为红灯。依次完成，不提前 T03：

1. 类型/schema 与样例回归：两参数 preview 成功、release 失败；默认 profile 原值；未知字段、非法 ID/版本、枚举/数值/必填字段失败。跨题相同选项 ID、跨资源 p1、text accepted 自然语言必须有通过用例。
2. 语义负例：集合重复、manifest/文件 ID 错配、缺引用、unit family 不一致、choice 答案不存在、order 丢词/重复、gap 孤立/重复、共享本地选项冲突、歧义 distractor、空逐空解析、错误 evidence；uniqueOptions 测试存在可行匹配与不存在匹配两种情况。
3. 作者组装：fixture 原样复制，拆分重组 deep equality；改变文件枚举顺序不改变产物；缺 profile/未启用 section 失败，启用 listening 但包无 listening 可通过。
4. 文件/字节安全：路径逃逸及符号链接、HTML/脚本、外部媒体、缺听力音频引用、缺文件、错误类型、bytes/hash 篡改失败；输入 hash 错误不能被构建自动修正。合法来源 URL 不被当外部媒体错误。
5. 全集检查：draft/reviewed 不计数；审核人同作者、缺审核时间失败；满足单包条件的 published 小包可通过单包校验但不能代表全集通过；跨包重复不充量。每项可计算阈值独立测边界，缺证据报告明确，不能用总数测试替代。
6. 打包 CLI：临时目录构建成功，读回 JSON 和媒体独立核验 bytes/hash；连续构建逐字节相同；同版本异内容失败且旧文件不变；新版本允许且旧版保留；注入校验、写盘、catalog 替换失败，断言旧 catalog 不变且不存在缺文件引用。
7. repository：同 itemId 跨版本返回正确版本；不存在精确版本返回 undefined；不得隐式取最新，返回值变更不污染下次读取。
8. 运行全部门禁与 T01 回归，检查变更白名单并整理完整交付材料。
