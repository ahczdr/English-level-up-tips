# 高考英语个人学习软件：开发执行入口

> 版本：1.0，2026-09-08。用户已明确：面向基础薄弱高中生，手机或平板练习，以高考英语为内容，提高学习兴趣；本次仅要求详细开发计划。

**Goal:** 交付可在手机、平板浏览器使用的高考英语补弱 PWA，包含分层练习、错题复习、学习成果、离线课程和本地备份。

**Architecture:** 在现有仓库的 `apps/english-practice/` 新建独立 Vue 应用。以版本化课程包驱动所有题型，IndexedDB 作为个人学习记录来源；首版没有账号服务器和 AI 依赖。原 VitePress 书稿不迁移为应用页面。

**Tech Stack:** Node.js 24、npm、Vue 3、TypeScript、Vite、Vue Router、Dexie、Zod、vite-plugin-pwa、Vitest、Vue Test Utils、Playwright。T01 锁定实际版本并提交独立 package-lock.json。

## 已固定的决策

- 学习内容：高考词汇与词块、基础语法、句子理解、听力、阅读理解、七选五、完形填空、语法填空、应用文、读后续写。
- 入门路径：补基础 -> 有提示专项 -> 无提示专项，不以原卷难度强制开始。
- 地区：省份、考试年份和教材版本未提供；使用 `gaokao-common-training-v1`，不提供全国统一总分或整卷模拟。任何省份真实卷型配置必须先核验官方来源。
- 设备：先以 iOS/iPadOS 17+ Safari、安卓 Chrome 为兼容目标；是否支持其他浏览器由真机结果决定，浏览器可访问不等于可安装为完整 App。
- 数据：单设备本地保存，支持导出、整库恢复；跨设备自动同步不属于 v0.1。
- AI：不参与首版必需流程，静态解析、参考答案和写作自评即可运行。
- 第一可用交付：1 个完整单元 + 持久化 + 复习；v0.1 内容门槛为 30 次可调度学习内容及各专项最低资源量，不只交页面。
- 内容授权：默认原创材料；借鉴现有项目的交互，不未经核对复制代码、课文和音频。

## 里程碑

| 里程碑 | 任务 | 交付物 | 估算开发工作日 |
| --- | --- | --- | --- |
| M1 数据与基础练习 | T01-T05 | 完整短单元、保存与恢复 | 6-9 |

## 开工和收尾

开发工作目录固定为 `apps/english-practice/`；本文所有相对代码路径以该目录为根。计划样例复制进应用 fixtures 后才作为工程测试数据。当前仓库默认 Node 为 v22.22.3，T01 必须先切换至 Node 24。

T01 建立以下工程命令；现在只定义命令契约，尚不存在这些应用命令：

```bash
npm ci
npm run dev
npm run content:check
npm run typecheck
npm run lint
npm run test:unit
npm run build
npm run test:e2e
```

发布顺序：结构校验 -> 类型/代码检查 -> 规则测试 -> 生产构建 -> 浏览器回归 -> HTTPS 真机验证 -> 内容审核 -> 7 天试用。只在每一层实际通过后记录通过，模拟设备测试不能替代音频与安装真机测试。

## 验收记录格式

每个任务结束在 `planning/gaokao-english/verification-log.md` 创建或追加记录：任务 ID、提交 SHA、执行命令、退出码、关键结果、测试设备和浏览器版本、仍未验证事项。记录不包含用户作文正文、设备标识、API 密钥或真实姓名。此次计划不会创建已通过的产品测试记录。
